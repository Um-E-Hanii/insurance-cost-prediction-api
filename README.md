#### **Insurance Cost Prediction API**







This project predicts medical insurance cost using a trained Machine Learning regression model.







The model was trained in Python and saved using Pickle.  



A FastAPI backend was created to deploy the model as a local API.







#### **Tech Stack**



\\- Python



\\- Pandas



\\- Scikit-learn



\\- FastAPI



\\- Uvicorn



\\- Pickle







#### **Features**



\\- Trained ML regression model



\\- Saved model for reuse



\\- FastAPI backend



\\- Localhost API deployment



\\- Swagger UI testing
